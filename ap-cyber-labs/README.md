# AP Cybersecurity Investigation Labs: Evidence Files

All data is fictional. Run inside your class Linux VM (Kali or Ubuntu).

## Get the files
    wget -qO- https://raw.githubusercontent.com/GITHUB_USER/ap-cyber-labs/main/setup.sh | bash

One lab only (example, Lab 4):

    wget -qO- https://raw.githubusercontent.com/GITHUB_USER/ap-cyber-labs/main/setup.sh | bash -s 4

Then: `cd ~/lab4 && ls`

Needs `wget` and `unzip` (`sudo apt install unzip` if missing).
Student packets are in `pdfs/`.
